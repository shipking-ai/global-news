      Library — every way to show news

      Researched, then sorted honestly

      We researched every format a news page can use — video, wires, social, alerts, data — and checked what each one really costs and needs. Here's the full map, including what this page deliberately doesn't do.

      Live TV & clips

      On this page

      Official YouTube channel players that always show what's live now, plus an on-YouTube fallback per channel. Outlet web players (DW, Sky, France 24) are link-out only — their streams aren't offered for third-party embedding, and hotlinking their raw feeds isn't allowed.

      Headline ticker

      On this page

      The wire ticker up top, fed by the story snapshot, pauses on hover and goes static for readers who prefer reduced motion.

      RSS snapshot

      On this page

      Public RSS/Atom feeds from every outlet, pulled at build time because browsers often block direct feed fetches. Headlines and snippets only, always linking to the original story.

      Live blog & story timelines

      On this page

      Timestamped updates in landing order in The wire, plus Story timelines that rebuild each running story oldest-first from the snapshot — the highest-value breaking formats for a small site, and they need no API at all.

      Social wire

      On this page

      Bluesky's public API is free with no key, so outlet posts render as cards here. X, Instagram and Facebook allow single-post embeds but no free feed — that's why they're follow links, not a fake feed.

      Event globe, maps & data

      On this page

      Open GeoJSON feeds — USGS earthquakes, NASA EONET disasters and wildfires, NOAA alerts, GDELT news signals — refresh in the browser on the globe above. Weather via Open-Meteo (free, no key); markets via TradingView's free widgets, labelled delayed.

      Breaking alerts & push

      Needs a server

      Real web push (OneSignal's free tier covers 10,000 web recipients per message; Firebase/VAPID is the self-hosted route) needs a service worker, an account and each reader's opt-in — none of which a static page can hold. This page uses an in-page wire instead.

      News APIs

      Needs a server

      NewsData.io's free tier (200 credits/day, 12-hour delay, commercial use allowed) is the best of the keyed APIs; NewsAPI.org's free tier is dev-only with a 24-hour delay and its production tier jumps to $449/mo. Any keyed API needs a build step or proxy — a key in page code is a leaked key.

      Live chat & comments

      Needs a server

      YouTube live chat can sit beside a player, but it needs the current broadcast ID resolved through the Data API and brings a real moderation burden. Self-hosted comments on a breaking-news page are a spam magnet; discussion stays on the platforms.

      Podcasts & radio

      On this page

      In the Listen section above: native players fed straight from podcast RSS (NPR News Now, The Guardian's Today in Focus), no login and no platform lock-in. Spotify and Apple stay as “listen on…” links beside the players, because their embeds can gate full playback behind an account.

      Newsletters

      Link-out

      Signup forms from Buttondown (free to 100 subscribers), Substack, Beehiiv or MailerLite embed as plain HTML — but the list lives with the provider, and this page has no provider account to send from.

      Reddit as a wire

      Being shut down

      Reddit has announced its RSS feeds end 13 Nov 2026 and public API access ends Mar 2027, so nothing here is built on them. Reddit stays as follow links only.

      Paywalled live TV

      Not used

      CNN, Fox News, MSNBC and CNBC's full feeds sit behind TV-provider logins. The “free CNN live” sites are unofficial re-streams — excluded, always.

      Live sports scores

      Not used

      No dependable free, keyless, embeddable live-scores widget could be verified in research. The honest options are linking to official score pages or paying for a sports data API.
